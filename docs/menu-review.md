# Menu transcription review

## Source and limits
Read manually from the supplied angled menu screenshot, dated February 2020. No OCR was run, because no source file was exposed locally. This is a historical transcription requiring restaurant approval before public commercial use. English fields are translations; Romanian fields are authoritative. Capitalisation and obvious diacritics are normalised. Unusual printed names (including “Shepards Pie”, “Tagliatele”, and “Arabiatta”) are retained rather than replaced with conventional spellings. No allergens, weights, or dietary tags are invented.
