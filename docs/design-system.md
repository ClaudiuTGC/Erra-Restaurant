# Design system

Designed before implementation. Figma is unavailable in this session; editable SVG references in `docs/designs/` replace the requested Figma frames. No Figma file or link is claimed.

- Paper `#f7f4eb`; ink `#252b25`; olive `#34483d`; terracotta `#a44c35`; muted `#61645a`; rule `#d9d8cb`.
- Heading: Cormorant Garamond, weight 500; body: DM Sans, 400/500/600. Self-hosted WOFF2, Latin and Latin extended.
- Type scale: 12, 14, 16, 20, 28, 40, 64, 96 px; fluid display sizes.
- Spacing: 4, 8, 12, 16, 24, 32, 48, 64, 96 px. Content width 1280 px.
- Solid olive button, 48px minimum touch height, 4px radius. Secondary action uses underlined ink text.
- Menu card: number, serif name, right-aligned price, subdued description, fine lower rule.
- Section heading: uppercase letterspaced eyebrow, serif title, optional text link.
- Desktop nav: wordmark left, four links center/right, locale and reserve action. Mobile: compact wordmark, locale, disclosure navigation.
- Footer: paper/olive contrast, wordmark, address, phone, navigation; no invented social account.
- Focus: visible terracotta outline with offset. No essential animation; reduced motion disables scrolling/transitions.

SVG frames show layout and tokens; implemented browser screenshots provide the final responsive evidence. Home hero uses a purpose-made olive botanical/table illustration; menu uses typography rather than food photography.
